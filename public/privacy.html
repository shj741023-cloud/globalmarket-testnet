시험 서비스 안내

이 앱은 Pi Testnet 기능 검증용이며 실제 Pi, 실제 상품대금 또는 실제 거래를 처리하지 않습니다.

1. 수집하는 정보

Pi Testnet 로그인 과정에서 Pi 사용자 식별자와 사용자 이름을 처리합니다. 시험 상품, 채팅, 거래 조건, Test-Pi 결제 식별자 및 시험 활동 기록이 저장될 수 있습니다.

2. 이용 목적

로그인 확인, 시험 상품·채팅·거래 기능 제공, Test-Pi 결제 연동 검증, 오류 확인과 서비스 보안 목적으로만 이용합니다.

3. 보관과 삭제

정보는 Testnet 시험 운영에 필요한 기간 동안 Neon PostgreSQL 시험 데이터베이스에 보관됩니다. 시험 종료, 운영상 필요 또는 적법한 삭제 요청에 따라 삭제될 수 있습니다. 실제 개인정보나 민감정보를 입력하지 마십시오.

4. 제3자 서비스

Pi Network의 로그인·Testnet 결제 기능, Render의 서버 호스팅 및 Neon의 PostgreSQL 데이터베이스를 사용합니다. 각 서비스의 처리에는 해당 제공자의 정책이 적용될 수 있습니다.

5. 이용자 주의사항

지갑 비밀문구, API Key, 비밀번호, 실제 주소·전화번호·결제정보를 입력하지 마십시오.

6. 이용자 요청

이용자는 자신의 시험 데이터 조회·정정·삭제를 요청할 수 있습니다. 요청은 Pi Developer Portal에 공개된 앱 연락처를 통해 접수하며, 본인 확인 후 시험 운영 범위에서 처리합니다.

7. 방침 변경

시험 범위가 변경되면 이 문서를 갱신합니다. 시행일: 2026년 8월 22일.
